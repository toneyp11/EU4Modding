# AutomationTools — backlog

Running list of planned work and ideas, so we don't lose them. Newest context at top.

- (awaiting in-game test) **Auto-convert religion & culture tool** — new toggle with its
  OWN interval (`atools_convert_interval`, default 60 mo, cycles 12/24/60/120), fully
  decoupled from the shrink interval. Each convert run, every owned province whose
  religion/culture differs from its owner's has a 20% chance to flip toward the owner
  (`change_religion = owner` / `change_culture = owner`) — including same-group cases
  (Catholic→Orthodox) the AI never converts. Chance is tunable in `atools_convert_effect`.

- (awaiting in-game test) **Region-based breakaway tool — FULL (100-tag pool)** — toggle.
  Each run: (A) every nation cedes out-of-capital-region provinces to a LIVING independent
  core-holder; (B) `atools_pool_spawn_effect` recycles dead pool tags, then for each free
  tag runs `atools_pool_select` (finds a nation + a seed province = target region) and
  releases the tag owning that nation's provinces in that region — so each separate
  out-of-region block becomes its OWN new independent nation. Configured on spawn:
  change_government=monarchy + autocracy_reform + set_capital=seed (culture/religion come
  free from release). PROVEN primitives: `release=TAG` (literal → per-tag ladder),
  `set_capital=event_target`, `exists=<literal tag>` for recycling.
  - Pool = 100 tags AT0-AT9,AU..,AV..,AW..,AX..,AY..,AZ..,BT..,BU..,BV.. (all point at
    common/countries/atools_pool.txt). GENERATED by scratchpad/gen_pool.sh into
    common/country_tags/atools_tags.txt, common/scripted_effects/atools_pool_effects.txt,
    and 100 loc name/adj pairs. Re-run the generator to change pool size or spawn config.
  - Recycling: tag freed (`clr used flag`) when its nation dies (`NOT exists=TAG`).
  - Own interval (`atools_split_interval`, default 12mo).
